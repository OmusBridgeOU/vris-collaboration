# 提供フレーム

このディレクトリへPNG画像を追加すると、ビルド時にフレーム一覧へ自動追加されます。

画像の可視部分全体を縦横比を保って58mmの点線内へ収めます。印刷用の注文画像を生成するときだけ、縁付近の色を70mmの外周まで続けます。編集プレビュー、サムネイル、端末保存・共有画像では枠を外周へ拡張しません。位置や比率は利用者が変更できません。中央の写真を見せる部分は透明にしてください。周囲につながる枠色を持つ素材を推奨します。

ファイル名は重複しない `snake_case` を使用し、公開・印刷利用の許諾を確認した素材だけを追加してください。例えば `sample_frame.png` は画像だけの選択ボタンになり、ファイル名は表示されません。

同じファイル名をキーとして `credits.json` に制作者と任意のSNS・Web URLを記録してください。クレジットページには画像・制作者・SNS・Web URLを表示します。
